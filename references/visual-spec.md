# 墨夜视觉规范（公众号）

## 颜色
| 用途 | 颜色 |
|---|---|
| 底色（封面、章节方块、金句卡） | 墨夜暖黑 `#221A12` |
| 眉题 / 深底上的文字 | 奶油白 `#FBF4E6`（只做文字色，不再做底色） |
| 辅助小字、出处 | `#B5A78F` / `#9C8B74` |
| 正文 | `#3f3f3f`，15px，行距 1.85，字距 0.5px |
| 话题色 · AI/工具 | 酸绿 `#D8FF00`（墨夜黑上对比度 14.5:1） |
| 话题色 · 营销/IP | 浅粉 `#FF8CC6`（8.9:1）；冲击粉 `#FB2C8F` 只有 4.6:1，不压在墨夜黑上做大字 |
| 话题色 · 重磅 | 金黄 `#FFC937` |

一句话记：**粉色系里，压在深色上就换浅粉。**

## 字体
思源宋体 Heavy（Source Han Serif SC Heavy），SIL OFL 开源协议，免费商用。
下载：https://github.com/adobe-fonts/source-han-serif/releases ，放到仓库 `fonts/SourceHanSerifSC-Heavy.otf`，或直接装到系统里。

## 封面
- 设计稿 1283×383，3 倍导出 3849×1149
- 左 900×383 横版区（消息列表 2.35:1），右 383×383 方形区（转发卡片 1:1），中间 1px 分隔线 `#3A2E22`
- 横版大字 104px，方形大字 76px；纯色底 + 超粗大字 + 句号收尾 + 英文大写眉题
- 封面大字是标题的压缩钩子，不和标题重复

## 正文
- 章节编号：墨夜黑小方块 + 话题色数字（01、02…），标题墨夜黑粗体 18px 居中
- 金句：墨夜黑底 + 奶油白粗体 + 话题色 4px 左边线
- 重点句：荧光笔（话题色底 + 墨夜黑字），全文 5–6 处
- 图注 12px 灰色居中；结尾自我介绍前加 `· · ·` 分隔
